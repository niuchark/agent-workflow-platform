# Agent Flow Platform Design System

> 页面实现前先检查 `pages/[page-name].md`；存在时以页面覆盖规则为准。

**产品类型：** AI 工作流 / 开发者工具 / SaaS 管理台  
**设计拨盘：** 差异度 4/10 · 动效 3/10 · 信息密度 8/10  
**风格：** Technical Minimalism（技术型轻量界面）

## 设计原则

- 内容与运行状态优先，装饰退居二线；默认使用明亮、稳定的实体表面。
- 页面采用统一的工具栏、数据卡、内容卡和空状态结构。
- 4/8px 间距节奏；移动端 16px 页面边距，桌面端 24px。
- 玻璃效果仅用于顶栏、遮罩和浮层，不用于数据密集型卡片。
- 主要操作每屏保持一个；危险操作必须与普通操作分离。

## 颜色

| 语义 | Tailwind | Hex | 用途 |
|---|---|---|---|
| Brand | `brand-600` | `#0284C7` | 主按钮、选中态、关键链接 |
| Brand hover | `brand-700` | `#0369A1` | Hover / pressed |
| Canvas | `canvas` | `#F8FAFC` | 页面背景 |
| Surface | `surface` | `#FFFFFF` | 卡片、侧栏、弹窗 |
| Ink | `ink` | `#0F172A` | 标题、正文主色 |
| Muted | `muted` | `#64748B` | 次要说明 |
| Border | `line` | `#E2E8F0` | 边框、分隔线 |
| Success | `positive` | `#059669` | 正常、成功、在线 |
| Warning | `warning` | `#D97706` | 风险、配额提醒 |
| Danger | `danger` | `#DC2626` | 错误、删除、失败 |

状态不能只依赖颜色；必须同时使用图标、标签或文本。

## 字体与数据

- UI/正文：`font-sans`，优先 Inter 与系统字体。
- 标题：`font-display`，优先 Space Grotesk，系统字体兜底。
- ID、密钥、JSON、日志：`font-mono`。
- 页面标题 20px/600；卡片标题 16px/600；正文 14px/1.5；辅助文本 12px。
- 费用、Token、时长、计数统一使用 `tabular-nums`。

## 组件规范

- 页面容器：`flex min-w-0 flex-col`。
- 工具栏：移动端可换行；间距 12px；标题左、主操作右。
- 卡片：16px 圆角、1px `line` 边框；默认无阴影，hover 仅改变边框色。
- 表格：外层允许横向滚动，禁止让页面整体横向溢出。
- 输入与按钮：桌面高度 38px；主要触控目标至少 44px。
- 空状态：虚线边框、明确说明，并提供下一步操作。
- 弹窗：16px 圆角；遮罩可使用轻量模糊；危险确认按钮使用 `danger`。
- 工作流画布：节点状态使用颜色 + 文本/图标；选中态使用 2px 浅蓝 focus ring。

## 响应式

- 375px：单列卡片、工具栏换行、侧栏转为带遮罩的抽屉。
- 768px：双列卡片；筛选项可并排。
- 1024px：桌面侧栏；工作流节点库可见。
- 1440px：最多四列卡片；内容宽度上限 1600px。
- 固定元素不得遮挡键盘焦点；所有宽度必须验证 `scrollWidth === innerWidth`。

## 动效与可访问性

- 交互反馈 150–200ms，只动画 `opacity` 和 `transform`。
- 尊重 `prefers-reduced-motion`，禁用非必要动效。
- 所有可操作元素都有可见 `:focus-visible`；图标按钮必须有 `aria-label`。
- 保留跳过导航链接；路由内容使用可聚焦的 `main` 区域。
- 正文对比度至少 4.5:1；图标与控件边界至少 3:1。

## 禁止模式

- 页面级重复 CSS、组件内硬编码品牌色、随机圆角/阴影。
- 大面积玻璃拟态、重渐变、装饰性动画、Emoji 结构图标。
- 只在 hover 出现的唯一操作、不可关闭的移动侧栏、无标签表单。
- 为迁移 Tailwind 而在 JSX 中堆叠难以维护的超长 utility 字符串；复用模式放入 `@layer components`。
